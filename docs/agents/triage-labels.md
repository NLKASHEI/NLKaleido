# Triage labels

The defaults from `mattpocock/skills` are:

| Label | Purpose |
| --- | --- |
| `needs-triage` | Unclassified incoming item |
| `needs-info` | Reproduction details or a decision are missing |
| `ready-for-agent` | Small, scoped, testable work with no unresolved blocker |
| `ready-for-human` | Needs UI testing, credentials or a product choice |
| `wontfix` | Out of scope or intentionally declined |

This file defines the vocabulary; it does not assert that GitHub labels have already been created.
